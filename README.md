# 🚀 Free VPN Configs with Volume

ساب‌لینک اتوماتیک کانفیگ‌های رایگان V2ray با حجم واقعی!

## ✨ ویژگی‌ها

- ✅ **بروزرسانی اتوماتیک** هر ۵ ساعت یکبار
- ✅ **فقط کانفیگ‌های تست‌شده** با حجم واقعی
- ✅ **سازگار با Psiphon** برای اتصال ترکیبی
- ✅ **پروتکل‌های پشتیبانی‌شده**: VLESS, Shadowsocks, Trojan
- ✅ **رایگان و متن‌باز**

## 📱 لینک اشتراک

`````````
https://balochscript.github.io/free-vpn-configs/subscription.txt
`````````

این لینک را کپی کرده و در V2rayNG یا Nekobox قرار دهید.

## 🔧 نحوه استفاده

### 📲 روش ۱: استفاده مستقیم (ساده)

1. لینک بالا را کپی کنید
2. در **V2rayNG** یا **Nekobox**:
   - دکمه **➕** را بزنید
   - **اضافه کردن اشتراک** را انتخاب کنید
3. لینک را وارد کنید و **تایید** بزنید
4. دکمه **بروزرسانی** را بزنید
5. یک کانفیگ انتخاب کنید و **اتصال** را بزنید

---

### 🚀 روش ۲: اتصال ترکیبی V2rayNG + Psiphon (توصیه می‌شود)

این روش **حجم رایگان بیشتر** و **اتصال پایدارتر** می‌دهد!

#### 📱 مرحله ۱: تنظیم V2rayNG

1. **V2rayNG** را باز کنید
2. روی آیکون **منو** (☰ گوشه بالا) کلیک کنید
3. **تنظیمات** (Settings) را انتخاب کنید
4. به پایین اسکرول کنید و پیدا کنید:

**قسمت Core Settings (تنظیمات هسته):**
`````````
Local proxy port: 10808
`````````

**قسمت Advanced Settings (تنظیمات پیشرفته):**
`````````
Mode: Proxy only (فقط پروکسی)
`````````

5. **ذخیره** کنید و برگردید به صفحه اصلی

#### 📱 مرحله ۲: اضافه کردن ساب‌لینک

1. در صفحه اصلی V2rayNG، دکمه **➕** را بزنید
2. **اضافه کردن اشتراک** را انتخاب کنید
3. این لینک را وارد کنید:
`````````
https://balochscript.github.io/free-vpn-configs/subscription.txt
`````````
4. **تایید** → **بروزرسانی**
5. یک کانفیگ انتخاب کنید
6. دکمه **اتصال** را بزنید (V2rayNG باید وصل شود)

#### 📱 مرحله ۳: تنظیم Psiphon

1. **Psiphon** را باز کنید
2. به **گزینه‌ها** (Options) بروید

**بخش VPN Settings:**
- **Only tunnel selected apps** را تیک بزنید
- روی **Select apps** بزنید
- **تلگرام** (و هر برنامه دیگری که می‌خواهید) را تیک بزنید
- ⚠️ **مهم:** برنامه **V2rayNG** را تیک نزنید!

**بخش Proxy Settings:**
- **Connect through an HTTP Proxy** را تیک بزنید
- **Use the following settings** را انتخاب کنید:

`````````
Host address: 127.0.0.1
Port: 10808
`````````

3. برگردید و دکمه **شروع** (Start) را بزنید
4. چند دقیقه صبر کنید تا وصل شود

#### ✅ تبریک! اتصال ترکیبی برقرار شد

حالا ترافیک شما:
```
تلگرام → Psiphon → V2ray → اینترنت
```

این ترکیب **حجم رایگان** و **سرعت بالا** می‌دهد! 🎉

---

### 🐱 روش ۳: Nekobox + Psiphon

1. در Nekobox:
   - Settings → Route → Custom Outbound
   - Type: `HTTP`, Address: `127.0.0.1`, Port: `10808`
2. ساب‌لینک را اضافه کنید
3. مراحل Psiphon را مثل بالا تکرار کنید

## 💡 سوالات متداول

### چرا برخی کانفیگ‌ها کار نمی‌کنند؟

کانفیگ‌ها رایگان هستند و ممکن است پر شوند. چند کانفیگ مختلف امتحان کنید.

### چگونه سرعت را بهبود دهم؟

- از روش ترکیبی استفاده کنید
- کانفیگ‌های سریع‌تر انتخاب کنید
- در ساعات شلوغ کمتر استفاده کنید

### هر چند وقت بروزرسانی می‌شود؟

هر ۵ ساعت خودکار، یا دستی در V2rayNG

### آیا امن است؟

⚠️ برای کارهای حساس (بانک) استفاده نکنید. فقط برای دسترسی عمومی.

### چرا Psiphon لازم است؟

Psiphon حجم رایگان دارد. ترکیب آن با V2ray = حجم بیشتر + سرعت بهتر
