## 🔧 نحوه استفاده

### روش ۱: استفاده مستقیم

1. لینک بالا را کپی کنید
2. در V2rayNG یا Nekobox: **➕ → اضافه کردن اشتراک**
3. لینک را جایگذاری کنید
4. بروزرسانی را بزنید
5. یک کانفیگ انتخاب کنید و متصل شوید

### روش ۲: ترکیبی با Psiphon (توصیه می‌شود برای حجم بیشتر)

#### مرحله ۱: راه‌اندازی Psiphon

1. اپلیکیشن **Psiphon** را نصب کنید
2. Psiphon را باز کرده و منتظر بمانید تا وصل شود
3. بعد از اتصال، به تنظیمات Psiphon بروید و پورت HTTP Proxy را یادداشت کنید (معمولاً `8080` یا `8081`)

#### مرحله ۲: تنظیم V2rayNG

1. V2rayNG را باز کنید
2. به **تنظیمات** (Settings) بروید
3. گزینه **Route Settings** یا **تنظیمات مسیریابی** را انتخاب کنید
4. در قسمت **Outbound Proxy** یا **پروکسی خروجی**:
   - نوع: `HTTP`
   - آدرس: `127.0.0.1`
   - پورت: `8080` (یا همان پورتی که از Psiphon یادداشت کردید)
5. ذخیره کنید

#### مرحله ۳: اضافه کردن ساب‌لینک

1. در صفحه اصلی V2rayNG، دکمه **➕** را بزنید
2. **اضافه کردن اشتراک** یا **Add subscription** را انتخاب کنید
3. لینک اشتراک بالا را وارد کنید
4. بروزرسانی کنید
5. یک کانفیگ انتخاب کرده و متصل شوید
6. حالا ترافیک شما از طریق Psiphon + V2ray عبور می‌کند و حجم دارید! 🎉

### روش ۳: ترکیبی با Nekobox

1. Nekobox را باز کنید
2. Settings → Route → Custom Outbound
3. اضافه کردن Proxy:
   - Type: `HTTP`
   - Address: `127.0.0.1:8080`
4. ساب‌لینک را اضافه کنید

## 🛠️ راه‌اندازی برای توسعه‌دهندگان

### پیش‌نیازها

````bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
pip install -r requirements.txt
````

### دریافت API تلگرام

1. به آدرس زیر بروید:
   ````
   https://my.telegram.org
   ````

2. با شماره تلگرام خود وارد شوید

3. گزینه **API development tools** را انتخاب کنید

4. یک اپلیکیشن جدید بسازید و اطلاعات زیر را دریافت کنید:
   - `api_id` (یک عدد)
   - `api_hash` (یک رشته)

### تنظیم Secrets در GitHub

1. به ریپوی خود در GitHub بروید
2. **Settings** → **Secrets and variables** → **Actions**
3. دکمه **New repository secret** را بزنید
4. دو Secret زیر را اضافه کنید:

| Name | Value |
|------|-------|
| `TELEGRAM_API_ID` | api_id خودتان |
| `TELEGRAM_API_HASH` | api_hash خودتان |

### اجرای محلی (تست در کامپیوتر شخصی)

````bash
export TELEGRAM_API_ID="your_api_id"
export TELEGRAM_API_HASH="your_api_hash"

cd src
python scraper.py
python tester.py
python utils.py
````

### فعال‌سازی GitHub Pages

1. **Settings** → **Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `gh-pages` / `root`
4. **Save**

### اجرای اولین Workflow

1. **Actions** → **Update Free VPN Configs**
2. **Run workflow** → **Run workflow**
3. منتظر بمانید تا تمام شود (۵-۱۵ دقیقه)
4. لینک شما آماده است!

## 💡 سوالات متداول (FAQ)

### چرا برخی کانفیگ‌ها کار نمی‌کنند؟

- کانفیگ‌ها رایگان هستند و ممکن است پر شوند
- اپراتورهای مختلف (ایرانسل، همراه اول) نتایج متفاوتی دارند
- چند کانفیگ مختلف امتحان کنید

### چگونه سرعت را بهبود دهم؟

- از حالت ترکیبی با Psiphon استفاده کنید
- کانفیگ‌هایی با سرعت بالاتر (در نام کانفیگ نوشته شده) انتخاب کنید
- در ساعات شلوغی روز از استفاده سنگین خودداری کنید

### هر چند وقت بروزرسانی می‌شود؟

هر ۴ ساعت یکبار به‌صورت خودکار. می‌توانید در اپلیکیشن V2rayNG هم دستی بروزرسانی کنید.

### آیا امن است؟

کانفیگ‌های رایگان را **برای کارهای حساس استفاده نکنید**. فقط برای دسترسی عمومی به اینترنت مناسب هستند.
