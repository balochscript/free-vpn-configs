## 🔧 نحوه استفاده

### 📲 روش ۱: استفاده مستقیم (ساده)

1. یکی از لینک‌های بالا را کپی کنید
2. در **V2rayNG** یا **Nekobox**:
   - دکمه **➕** را بزنید
   - **اضافه کردن اشتراک** را انتخاب کنید
3. لینک را وارد کنید
4. دکمه **بروزرسانی** را بزنید
5. یک کانفیگ انتخاب کنید و **اتصال** را بزنید

---

### 🚀 روش ۲: اتصال ترکیبی V2rayNG + Psiphon (پیشنهاد ویژه)

این روش **حجم رایگان بیشتر** و **اتصال پایدارتر** می‌دهد!

#### 📱 مرحله ۱: تنظیم V2rayNG

1. **V2rayNG** را باز کنید
2. روی آیکون **منو** ☰ (گوشه بالا) کلیک کنید
3. **تنظیمات** (Settings) را انتخاب کنید
4. به پایین اسکرول کنید:

**Core Settings:**
``````````
Local proxy port: 10808
``````````

**Advanced Settings:**
``````````
Mode: Proxy only
``````````

5. **ذخیره** کنید

---

#### 📱 مرحله ۲: اضافه کردن ساب‌لینک

1. دکمه **➕** را بزنید
2. **اضافه کردن اشتراک** را انتخاب کنید
3. یکی از لینک‌های بالا را وارد کنید
4. **تایید** → **بروزرسانی**
5. یک کانفیگ انتخاب کنید و **اتصال** بزنید

---

#### 📱 مرحله ۳: تنظیم Psiphon

1. **Psiphon** را باز کنید
2. به **Options** بروید

**VPN Settings:**
- **Only tunnel selected apps** ✓
- **Select apps** → **تلگرام** ✓
- ⚠️ **V2rayNG را تیک نزنید** ✗

**Proxy Settings:**
- **Connect through an HTTP Proxy** ✓
- **Use the following settings**:

``````````
Host: 127.0.0.1
Port: 10808
``````````

3. **Start** را بزنید

---

#### ✅ تبریک!

``````````
تلگرام → Psiphon (حجم رایگان) → V2ray → اینترنت
``````````

## 🔍 نحوه کار (پشت صحنه)

1. **جمع‌آوری**: از ۷ کانال تلگرام کانفیگ جمع می‌شود
2. **حذف تکراری**: کانفیگ‌های مشابه حذف می‌شوند
3. **تست اتصال**: درخواست HTTP از طریق پروکسی (Alive یا نه؟)
4. **تست حجم**: دانلود فایل 5MB (حداقل 2MB دانلود شود)
5. **فیلتر نهایی**: دو لیست جداگانه ساخته می‌شود
6. **انتشار**: در GitHub Pages منتشر می‌شود

## 💡 سوالات متداول

### چرا برخی کانفیگ‌ها کار نمی‌کنند؟

کانفیگ‌ها رایگان هستند و ممکن است:
- پر شوند یا خاموش شوند
- با اپراتور شما سازگار نباشند

**راه‌حل:** چند کانفیگ امتحان کنید.

- در ساعات شلوغ کمتر استفاده کنید
